연예인 사진 넣는 방법
====================

1) 이 폴더(celebs/)에 사진 파일을 넣으세요.
   예) 1.jpg, 2.jpg, iu.jpg, karina.png ...
   - 정사각형에 가까운 얼굴 사진이 제일 예쁘게 나옵니다.
   - jpg / png 모두 가능.

2) index.html 을 열고 상단의 CELEBS 목록만 수정하세요.

   const CELEBS = [
     { name: "아이유",   img: "celebs/iu.jpg" },
     { name: "카리나",   img: "celebs/karina.jpg" },
     ...
   ];

   - name: 화면에 보일 이름
   - img:  "celebs/파일명" (이 폴더 기준 경로)

3) 사진이 없거나 파일명이 틀리면 자동으로 '실루엣 자리표시자'가 뜨고,
   게임은 그대로 동작합니다(사진만 안 보임).

주의
----
- 외부 사이트 URL(https://...)을 img 에 직접 넣으면 '결과 저장' 시
  브라우저 보안(CORS) 때문에 이미지 저장이 안 될 수 있어요.
  가급적 이 폴더에 파일로 직접 넣어주세요.
- 사진 개수는 원하는 만큼 늘리거나 줄여도 됩니다.
